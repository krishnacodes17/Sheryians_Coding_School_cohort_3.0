# css (cascarding style sheets)

## What is CSS?
- CSS is a language used to style HTML documents. It allows you to control the layout, colors, fonts, and overall appearance of a web page. CSS works by selecting HTML elements and applying styles to them.

## Why use CSS?
- CSS separates content from presentation, making it easier to maintain and update the look of a website without changing the underlying HTML structure. It also allows for greater flexibility and creativity in design, enabling developers to create visually appealing and responsive websites.

## Basic Syntax
 
      keyword {
       property: value;
     }
### eg
    p {
      color: blue;
      font-size: 16px;
    }
