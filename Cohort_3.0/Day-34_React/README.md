# useState
- useState is a Hook that allows you to have state variables in functional components. You can call it inside a function component to add some local state to it. React will preserve this state between re-renders.


- syntex: 
```javascript
const [state, setState] = useState(initialState);
````
- state: The current state value.
- setState: A function that lets you update the state.
- - setState do two things:
  - It updates the state variable to the new value.
  - its re-renders the component
